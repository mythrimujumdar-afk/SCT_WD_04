\# Task 04 - To-Do Web App



A simple and user-friendly To-Do Web App developed as part of my SkillCraft Technology internship.



\## Features



\- Add and manage tasks

\- Mark tasks as completed

\- Edit tasks

\- Delete tasks

\- Set date and time for tasks

\- Filter tasks by All, Pending and Completed

\- 12-hour time format

\- Tasks are saved using localStorage



\## Technologies Used



\- HTML

\- CSS

\- JavaScript
